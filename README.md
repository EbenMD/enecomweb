# Enecom IT Solutions GH — Website

A responsive, multi-page static website for GitHub Pages.

## Included
- Home, About, Services, Training & Fees, Contact pages
- Responsive mobile navigation
- Course search and category filter
- WhatsApp contact buttons with prefilled messages
- Contact form that opens WhatsApp (no backend or database)
- Company logo SVG, SEO page titles/descriptions, starter robots.txt and sitemap.xml

## Before publishing
1. **Confirm all training fees.** The prices on `training.html` are proposed illustrative prices and are not verified/approved. Edit the course data and the pricing disclaimer in `training.html`.
2. Confirm business address and contact details.
3. Replace `YOUR-DOMAIN.example` in `robots.txt` and `sitemap.xml` with your real public domain/URL. If keeping GitHub Pages at `https://ebenmd.github.io/enecomweb/`, update sitemap URLs to that exact base URL and ensure the sitemap path works.
4. The official logo supplied by the user is included as `assets/enecom-logo.png` and is used in the header, footer and favicon reference. If you replace it later, update the image references in the HTML files.
5. Check every WhatsApp button and form on a phone and desktop before announcing the website.

## Publish to GitHub Pages
1. Extract the ZIP.
2. Open the GitHub repository for your site.
3. Upload all files and folders from this package to the repository's publishing root (usually `/` for the configured branch).
4. Commit the changes.
5. Open **Settings → Pages** and confirm the branch/folder being published.
6. Visit the published URL and test navigation, course filters and WhatsApp links.
